# hotel-booking-insights-dashboard

📌 Overview
This Power BI dashboard analyses hotel booking performance, customer behaviour, cancellation trends, and revenue insights using real-world hotel booking data.

🎯 Objectives
Analyse booking and cancellation behaviour
Identify revenue trends and revenue leakage
Understand customer and booking channel performance
Support business decision-making using data insights

📊 Key Metrics
Total Revenue
Revenue Lost
Average Daily Rate (ADR)
Cancellation Percentage

🔍 Key Insights
Peak booking demand occurs during specific seasonal periods
Certain customer groups show higher cancellation behaviour
Revenue loss is strongly influenced by booking cancellations
Longer lead times are associated with higher cancellation percentages

🛠 Tools Used
Power BI
Power Query
DAX
Excel
